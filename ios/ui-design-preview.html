功能瓦片网格

主页用 2 列瓦片承接所有新模块（表盘、传感器、设置等）。新功能只需新增一个瓦片配置（图标 / 标题 / 副文案 / 目标页面），不改主页骨架；瓦片支持「即将上线」的虚线占位态。

集中式 Theme 令牌

颜色、圆角、间距、字号全部收敛到一个 Theme 常量文件，落地时对应 SwiftUI 的 Color / CGFloat。后续换肤、深色微调只改一处，不散落各视图。

导航预留

底部导航先占位（主页 / 设备 / 中央 + / 消息 / 我的），中央悬浮按钮留作快速入口。当前只有两页，导航可在功能增多后再启用，不影响现有流程。

动画与反馈边界

全部使用 SwiftUI 原生：withAnimation(.spring(...))、transition、进度条插值；关键操作（配对成功、上传完成、失败）接 UINotificationFeedbackGenerator 触觉反馈。iOS 16 不可用的 API 不使用。
